### 3.1 一键启动（推荐，便携版）

项目自带完整工具链（`.tools`），**无需预装任何环境**：

```powershell
# 双击或执行

# 或
powershell -ExecutionPolicy Bypass -File D:\java\start-all.ps1
```

脚本行为（幂等，可重复执行）：
1. 装载 `.tools` 下随包的 JDK 17 / Node 24 / Maven / MySQL 8.0 / Redis 5.0。

3. 首次运行自动建库并导入演示数据（`init-db.ps1`）。
4. 启动后端 jar（8082）与前端 dev server（5175）。

停止：`stop-all.cmd` 或 `stop-all.ps1`。

## 5. 接口规范与清单

### 5.1 通用约定

- 统一返回 `Result<T>`：`{ code, message, data }`。
- HTTP 状态码与业务码同值（400/401/403/404/409/500）；业务冲突（如 `DuplicateKeyException` 的 1001）返回 HTTP 200 + body 1001。
- 鉴权：`Authorization: Bearer <token>`。
- 项目上下文：路径变量 `pid` 优先，`X-Project-Id` 头兜底（资产维度接口依赖该头）。
- 分页：`PageResultVO` 统一包装。

## 6. 核心技术实现

### 6.1 鉴权（JwtInterceptor + UserContext）

- 用 `HandlerInterceptor` 而非 Spring Security：鉴权模型是「登录态 + 项目级 RBAC」，引入 Security 会把整套过滤器链一起接过来。
- 拦截器失败**直接写响应体**而非抛异常，避免「handler 为 null 时是否命中全局 advice」的实现差异。
- CORS 预检（OPTIONS）放行。
- 登出黑名单：`jti` 命中即拒绝。
- `afterCompletion` 中 `UserContext.clear()`——Tomcat 复用线程，不清理会「随机以别人身份操作」。

### 6.2 项目级 RBAC（@ProjectPermission + AOP）

- `ProjectIdResolver` 是**纯函数**，从 `@ProjectId` 注解 + 方法参数 + URI + `X-Project-Id` 头解析 projectId（路径优先、头兜底）。
- 切面查询 `project_member` 时 `project_id + user_id + status=ACTIVE` 三者缺一不可，防跨项目越权。
- 权限判定统一走 `RolePermissionMap.allows()`，业务代码不出现散落的 `"OWNER".equals(role)`。

### 6.3 缓存（RedisCacheGateway + 主动失效）

- 概览缓存按项目维度，TTL 10 分钟；写操作主动失效。
- `RedisCacheService.get(key, TypeReference<T>)` 重载解决 `List<T>` 泛型擦除后的 `ClassCastException`。
- 统计缓存失效挂在 `ProjectOverviewCache#evict()` 通道上。

### 6.4 分片上传（ChunkUploadService + ChunkMerger）

- `init` 分配 uploadId，分片落 `{temp-path}/{uploadId}/{index}.part`。
- 分片可乱序上传，`complete` 时 `ChunkMerger` 按序合并 + MD5 校验。
- `ChunkCleanupTask`（`@Scheduled`，cron 可配）清理过期残留会话。

### 6.5 存储抽象（StorageService）

```java
public interface StorageService {
    String store(UploadSource source);      // 存储并返回 file_key
    void delete(String fileKey);
    byte[] load(String fileKey);
    // ...
}
```

`LocalStorageService`（默认）与 `MinioStorageService`（占位）实现，`gameasset.storage.type` 切换。

### 6.6 乐观锁（任务拖拽）

- `task.version` 乐观锁，`TaskMoveDTO` 携带 version，冲突抛 409。
- `TaskSortOrderCalculator`：按相邻卡片 `sort_order` 取中值，`< 10` 时整列重排。

### 6.7 通知（NotificationService.push 统一入口）

触发点：任务指派 / 改列 / 评论与 @提及 / 资产审核 / 任务临近截止（`TaskDueReminderTask`，按天幂等）。硬规则「不给自己发通知」。

### 6.8 统计（BurndownCalculator / WorkloadBalanceCalculator）

- 燃尽图：理想线逐日线性递减；实际线按 `task_status_log` 回放，判定 AHEAD / ON_TRACK / BEHIND。
- 工作量均衡度：总体标准差（÷n），μ=0 取 1.0，可为负不截断。

### 6.9 前端请求层（request.ts 拦截器）

- **请求拦截器**：注入 `Authorization` + `X-Project-Id`（从 `projectStore.currentId`）。
- **响应拦截器**：后端对业务失败同时设 HTTP 状态码与 body code，两个分支都处理；401 统一清登录态跳登录页（加锁防并发弹窗）。
- 导出走 `responseType: 'blob'`，不用 `window.open`（原生导航带不上 Bearer 头会静默 401）。

### 6.10 ECharts 图表

- `useEcharts.ts`：统一生命周期（init / resize / dispose），**SVG 渲染器**（无头浏览器 `--dump-dom` 能看到真实节点，便于渲染冒烟断言）。
- `useChartTheme.ts`：从 `:root` 读 CSS 变量作为配色，深色主题自动跟随。

### 8.4 生产环境注意

- `gameasset.jwt.secret` 必须用环境变量注入，勿用默认值上线。
- 存储类型可切换 `minio`（当前为占位实现，需补 MinIO SDK 与实现）。
- 数据库连接、存储路径等均支持环境变量覆盖（`DB_HOST/DB_PORT/DB_NAME/DB_USERNAME/DB_PASSWORD/STORAGE_PATH/CHUNK_TEMP_PATH`）。
